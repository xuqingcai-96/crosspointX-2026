# crosspointX-2026

课还没交 · 初始原型

Reverse UX Challenge：以在线教学实训平台的学生端功能为骨架，用八处刻意设计的交互障碍构建一条可完成的任务流程。独立赛事原型，与头歌平台无隶属关系。

## 启动

需要 Node.js，无第三方依赖。

```sh
node server.mjs
```

打开终端打印的 Local 地址，默认 http://127.0.0.1:4173 ；端口被占用时会自动选择 4174–4183 中的空闲端口。页面也可部署到任意支持静态文件的 HTTP/HTTPS 服务。请通过 HTTP 打开，勿直接双击 HTML：模块与 Worker 需要 HTTP 环境。

```sh
node --test tests/core.test.mjs
```

## 功能范围

- 工作台、三门示例课程、一个可完成的 JavaScript 实训任务。
- 任务书、教学资料、课堂公告、代码编辑、保存、导出。
- 浏览器 Worker 真实执行代码，8 个测试用例，2 秒执行上限；评测历史与错误详情。
- 运行申请、固定 6 秒人为等待、代码附件提取或本地上传、归档材料校验、三轮确认。
- 正式提交回执（JSON 下载）、成绩管理、设计说明、完整通关路线、演示重置。
- 进度存储在当前浏览器 localStorage；无云端账号、真实学校系统、教师管理端或多用户共享数据。

## 三分钟演示路线

1. 学习中心 → 课程事务 → 实践记录 → 第 1 关。
2. 查阅资料与公告，在代码中把 `return a - b` 改为 `return a + b`。
3. 保存草稿，申请运行。用途任选，次数填 1，理由填写至少 8 个字符。
4. 看到 99% 人为等待后，评测通过并生成 `EVAL-...` 编号。复制编号。
5. 办理成果归档，点击“提取当前代码”。先尝试错误材料，可到事务记录查看恢复提示。
6. 填写：
   - 课程：`JavaScript 程序设计`
   - 作业：`第 1 关：两个数的和`
   - 文件名：`JS_L01_20260001.js`
   - 编号：刚才复制的最新通过编号
   - 说明：`完成求和函数并通过全部八个测试用例`
7. 完成三轮确认：勾选、输入“确认归档”、再次勾选并最终提交。
8. 下载回执，查询 100 分成绩。侧栏“设计说明 / 演示”可查看机制、答案与重置入口。

## 八处机制

混乱导航、信息碎片化、隐藏归档要求、运行申请、模糊错误、99% 人为等待、结果编号人工搬运、过度确认。

错误条件固定且有恢复途径；代码不会随机失败；等待有明确结束；修改评测后的代码会使当前通过状态失效。代码附件必须与当前评测版本一致。正式归档后锁定本次代码，重新演示请重置。

## 交付边界

本版本完成可运行原型，未制作赛事海报。海报必须另外通过 Dify 的 AMD 插件生成，可以再编辑。当前 Worker 是演示用隔离执行环境，不是面向不可信公网代码的生产级判题沙箱；若扩展为真实教学服务，应接入独立受限的判题基础设施。
