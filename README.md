# crosspointX-2026

课还没交 v0.3：支持教师发布、学生提交、教师核实的 Reverse UX Challenge 原型。独立赛事作品，与头歌平台无隶属关系。

在线地址：https://course-not-submitted-ux.xuqingcai96.chatgpt.site

## 师生操作

1. 教师在首页创建课堂，进入「课堂与身份」保留教师恢复口令。
2. 新建作业，填写标题、任务说明、归档前缀及可选截止时间。评测模板支持求和、最大值、乘积。
3. 保存只生成草稿。到「教学任务备案」单独发布，学生才可见。
4. 复制学生邀请链接或提供课堂码。学生使用昵称、演示学号加入。
5. 学生从「学习中心 → 课程事务 → 实践记录」进入任务，查看分散在资料和公告中的要求。
6. 编写代码，申请运行，真实执行 8 个测试用例，申请中包含固定 6 秒处理等待，与运行申请合为一个机制。
7. 抄写评测编号，按始终可见的归档要求填写课程、作业、文件名和说明，提取代码后完成三轮确认。
8. 提交后回到原编辑页，不显示成功弹窗、不清空代码。进入「提交记录」核对新增的带时间、版本和编号的回执。
9. 教师在「成果核实队列」检查代码与材料，保存评分后，成绩先处于「待发布」。教师必须逐条打开记录、勾选并发布；没有批量发布。也可填写原因退回。
10. 学生只能在教师逐条发布后看到成绩和评语，未发布信息在学生接口中也会隐藏。退回后可修改并提交新版本，原版本保留。

同一设备可以从顶部切换已保存的教师和学生身份。其他设备可凭各自的恢复口令继续对应身份；学生邀请链接只含课堂码，不含教师口令。

## 本机开发

需要 Node.js 22.13 或更新版本，推荐 Node.js 24；没有第三方依赖。

```sh
node server.mjs
```

打开终端打印的 Local 地址，默认 4173 端口，被占用时自动选择 4174–4183。使用内置 SQLite，数据库位于已忽略的 `.local-data/classroom.sqlite`。本地数据库与线上 D1 数据库独立。

```sh
node --test tests/core.test.mjs tests/classroom.test.mjs
node scripts/build.mjs
```

## 线上结构

- `dist/`：手写前端资源，使用浏览器 Worker 运行学生 JavaScript。
- `dist/classroom.mjs`：评测模板、学生材料校验、教师任务校验。
- `worker/api.mjs`：同源 API、教师和学生身份校验、课堂隔离、提交版本、核实与评分。
- `worker/local-db.mjs`：本地 SQLite 的 D1 兼容层，仅用于本地开发和测试。
- `drizzle/0000_classroom.sql`：云端 D1 结构迁移；请求处理中不创建表。
- `scripts/build.mjs`：将 API 与静态资源打包为单个自包含 `dist/server/index.js`，适用于 Cloudflare Worker / Sites。

部署使用已存在的 Sites 项目，保留原项目 ID 和公开访问设置，将 `.openai/hosting.json` 从静态配置改为 Worker 配置，删除 `static` 并声明 `"d1": "DB"`。Sites 发布时应用结构迁移。仓库的 `deployment/hosting.example.json` 提供逻辑绑定示例，不包含托管身份或凭证。

## 范围和身份

这是公开赛事演示：不接入学校实名账号。教师和学生使用独立随机恢复口令，服务端只保存口令哈希；学生不能凭课堂码取得教师权限。课堂记录可跨设备共享，代码草稿与身份口令保存在各自浏览器。旧版独立演示的 localStorage 不会被清除。

浏览器评测是辅助记录，不是可信的考试判题证明。提交时服务端检查版本、材料和结果结构；最终成绩必须由教师核实并逐条发布后可见。若用于真实教学，应接入学校身份系统及独立判题沙箱。

六类核心机制：信息碎片化、申请式运行（含等待）、手动搬运结果、过度确认与语义绕弯、提交弱反馈、教师逐条发布成绩。隐藏要求和模糊报错已删除；导航改造留待最后的 UI 美化。错误直接指出原因和修复方式，代码执行有 2 秒上限。

可选的指定方法、额外评语门槛、倒计时清空、禁止粘贴、恶意低分或投诉，本版不加入。代码草稿保留，已提交版本作为不可变快照保存，提交后继续编辑不会覆盖回执中的代码。

`drizzle/0001_grade_publication.sql` 是追加的结构迁移，保留旧版已经公开的成绩；新核实成绩需显式发布。

赛事海报尚未制作，必须另外通过 Dify 的 AMD 插件生成。
